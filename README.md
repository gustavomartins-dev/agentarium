# Lembrete de Água

Aplicativo pessoal para lembrar de beber água ao longo do dia.

## Objetivo

Receber lembretes no celular em intervalos configuráveis e registrar rapidamente quando eu beber água, sem depender de manter o aplicativo aberto.

## Primeira versão

- Configurar horário de início e fim dos lembretes
- Escolher o intervalo entre notificações
- Receber notificação local com som e vibração
- Marcar uma quantidade de água como consumida
- Visualizar o progresso diário
- Pausar os lembretes temporariamente
- Manter dados e preferências no próprio aparelho

## Decisões pendentes

- Android apenas ou Android e iPhone
- Meta diária fixa ou calculada pelo perfil
- Tecnologia do aplicativo
- Identidade visual e nome definitivo

## Ideias futuras

- Atalhos de 200 ml, 300 ml e 500 ml
